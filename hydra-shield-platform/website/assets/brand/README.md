# Talaix brand assets

Canonical brand artwork for the platform. **The three master files are the
design source of truth — never edit them in place.** Derived variants are
regenerated by `scripts/brand_variants.py`.

## Masters (designer originals — do not modify)

| File | Content |
|---|---|
| `logo-master.png` | The T + teal dot mark (navy on white) |
| `logo-with-text-master.png` | Mark + TALAIX wordmark |
| `logo-text-site-master.png` | Mark + wordmark + talaix.com |

## Derived variants (regenerate — never hand-edit)

Generated by `python scripts/brand_variants.py` (idempotent):

| File | Used for |
|---|---|
| `favicon-16.png` / `favicon-32.png` | Browser favicons (white background, visible on light and dark tabs) |
| `apple-touch-icon.png` | 180×180 iOS touch icon (mark centred on white) |
| `logo-mark-inverted.png` | White T + teal dot on transparent — for the DARK navbar / footer / registry topbar |
| `logo-with-text-inverted.png` | Same inversion with the wordmark — dark surfaces needing the full lockup |
| `logo-email.png` | Mark + wordmark, 400px wide on white — transactional-email header lockup |

The inversion keeps the teal dot's original colour and turns the navy
artwork white with luminance-derived alpha (background becomes transparent,
anti-aliased edges preserved).

## Usage map (where each variant is referenced)

- Navbar + footer brand mark: `logo-mark-inverted.png` (via `website/js/chrome.js`)
- Registry pages (`/api/sources`, `/api/v2/hazards`): `logo-mark-inverted.png` (`src/dashboard/registry_pages.py`)
- Favicons: all `website/*.html` reference `favicon-16/32.png` + `apple-touch-icon.png`
- PDF letterheads (verification / press reports): `logo-master.png` via
  `_brand_mark()` / `_title_with_mark()` in `src/dashboard/verification_report.py`
- Transactional-email HTML shell (welcome, verification, alerts, …):
  `logo-email.png` via `_minimal_html()` in `src/dashboard/mailer.py`
  (hosted URL built from `HYDRASHIELD_BASE_URL`)
- Masters: keep for future design work (print, social cards, presentations) —
  copy from here, never re-create.

## Colours

- Brand teal (the dot): `#47B3A8` (`--brand-teal`)
