The server URL

https://talaix.com/api/mcp

Public, read-only, rate-limited to 30 requests/minute per client. No API key required.

Background

What is MCP, in one paragraph

MCP (Model Context Protocol) is a standard that lets an AI assistant call external tools instead of guessing. Talaix publishes its evidence engine as such a server, so any MCP-capable assistant can run a real hazard analysis, verify an asset or pull the data-source registry — with the source, date and confidence attached to every figure.

Four steps

From zero to your first call

Install an MCP-capable app

Claude Desktop, Cursor or VS Code with Copilot — open it and sign in to your account there.

Open its MCP settings

Usually Settings → MCP, an mcp.json file, or "Connectors" in Claude.

Paste the configuration

Add the Talaix server (see the table below), then restart the app.

Ask a normal question

For example: "Analyse flood and wildfire risk at 45.42, 12.33". The assistant calls the Talaix tools and answers with the evidence.

Per client

Add it to your client

Exact wording varies by app version — check your client's documentation if something moved.

ClientHowConfiguration
Claude Desktop / Claude.ai Settings → Connectors → "Add custom connector" and paste the URL. Or the config file claude_desktop_config.json. 
{ "mcpServers": { "talaix": { "url": "https://talaix.com/api/mcp" } } }
Cursor Config file ~/.cursor/mcp.json (global) or .cursor/mcp.json (per project), or Settings → MCP. 
{ "mcpServers": { "talaix": { "url": "https://talaix.com/api/mcp" } } }
VS Code (Copilot) File .vscode/mcp.json — note the key is servers, not mcpServers. 
{ "servers": { "talaix": { "type": "http", "url": "https://talaix.com/api/mcp" } } }
Claude Code (CLI) One command in your terminal. 
claude mcp add --transport http talaix https://talaix.com/api/mcp
Windsurf · Cline · Continue · Zed · LM Studio All support MCP; add the server from their own MCP file or screen, using the same shape (mcpServers → url). url: https://talaix.com/api/mcp
Download?

Do you need to download a program or a service?

Yes the client app

The user must have an AI assistant that supports MCP. Some are free (Cursor, VS Code, Claude Code); Claude Pro/Max is a subscription.

No from Talaix

Talaix is a cloud service reached by URL. The user installs nothing from Talaix, runs no server, and needs no VPN or open ports.

One exception. Older clients that only support local (stdio) servers need a small bridge called mcp-remote (run with npx, requires Node.js). Modern clients that support HTTP transport (Streamable HTTP) need no bridge at all.
Technical notes

What to expect

Transport

  • Streamable HTTP request/response — no SSE streaming in this version.
  • Public read-only, 30 requests/minute per client.
  • Verified live: the server answers with protocolVersion 2025-06-18 and 9 tools.
