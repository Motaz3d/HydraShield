Verify a Talaix document

Every report and digital product issued by the Talaix TX engine carries an authenticity seal: TX-XXXX-XXXX-XXXX. The seal is shown in the PDF footer and in JSON responses. Use this page to confirm that a document was genuinely issued by the platform.

Verify by seal code

Enter the code exactly as it appears. Example: TX-1A2B-3C4D-5E6F.

Advanced: stateless verification with JSON payload

For JSON analysis results, paste the original payload and the seal code. The platform recomputes the seal locally and tells you whether they match.

Where to find the seal

On every PDF report the seal appears in the footer, after the report ID. In JSON responses it is under authenticity.code.

What the seal proves. The seal confirms that the document or payload was issued by the Talaix TX engine. It does not prove that every statement in the content is true; data gaps, model limitations and evidence statuses are disclosed honestly inside each product.
