name=HydraShield Climate Intelligence
description=Climate-extreme intelligence from real data: analyze a point against the HydraShield API (wildfire, flood, drought, extreme heat, extreme wind, coastal) and browse the hazard registry with official sources and provenance. Core analysis works without an account; saving locations, monitoring and SMS alerts require a free HydraShield account; higher limits require a subscription (hydrashield.earth).
about=HydraShield brings together scientific evidence, Earth observation, official open data and historical events to understand environmental extremes, who and what is exposed, the economic implications, and practical resilience actions. This plugin is a client of the public HydraShield API: all computation happens server-side, every result carries its evidence class and provenance, and unavailable data is shown as unavailable — never filled in. Levels are screening indicators, not validated predictions. No credentials are required for the free analysis endpoints; an optional API key (subscriber feature) is stored only via the QGIS Authentication System (authcfg), never in project files.
