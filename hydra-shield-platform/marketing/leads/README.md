# Leads ledger

One JSON file per organization, following `schema.json`. **This ledger
starts empty by design** — records are created only from real, checkable
research (see `marketing/README.md` honesty rules). No placeholder or
example leads are committed.

File naming: `<organization-slug>.json`. Update `outreach_status` and
append to `interactions` as reality changes; bump `date_checked` whenever
the record is re-verified.
