=== ONE SENTENCE DESCRIPTION ===

=== SHORT DESCRIPTION (3 SENTENCES) ===
Talaix turns Earth-observation and official open data into climate-risk compliance evidence for EU disclosure (CSRD/ESRS E1, EU Taxonomy DNSH, EUDR). Companies get site-coordinate multi-hazard screening where every value carries its source, date and evidence status, plus machine-readable XBRL from our CsrdTX rules engine — sold as transparently priced evidence packs. The analytical engine itself is open source (EUPL-1.2, github.com/Motaz3d/tore), so technical diligence can read the code before the first call.

=== USP (3 FACTORS) ===
1. The only transparently priced physical climate-risk evidence: specialists (Jupiter, Climate X, Mitiga, XDI) sell opaque 5–7-figure enterprise contracts; GRC/CSRD suites (Workiva, Position Green, SAP) manage workflow but generate no physical-risk evidence at all. We publish our prices: €19 per report, €49–249/month. 2. Audit-grade honesty as architecture, not marketing: every datapoint carries its source, method, reference period and evidence class (OBSERVED → ESTIMATED → FRAMEWORK → UNKNOWN) — "unavailable is stated, never filled in". The analytical engine is open source (tore, EUPL-1.2), so any auditor can verify the code instead of trusting a black box. 3. Compliance-native output at near-zero marginal cost: evidence maps directly to CSRD/ESRS E1 datapoints with machine-readable XBRL from our CsrdTX rules engine — self-serve from site coordinates to audit-ready pack in minutes, fully automated (no consultants), so the €19 entry tier is economically impossible for incumbent vendors.
