# Procurement & tender radar

One JSON file per procurement/tender opportunity, following `schema.json`.
**Empty by design** — records only from official portals (TED, national
procurement portals, institutional tender pages), live-checked. This is
the procurement complement to the funding knowledge base
(`config/funding_knowledge.json`) and the EU funding ledger
(`marketing/eu_funding/`): funding ≠ procurement — a tender is a purchase
of services, a grant is not.
