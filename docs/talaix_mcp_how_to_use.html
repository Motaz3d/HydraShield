كيف يستخدم المستخدم العادي خدمة Talaix عبر MCP؟

السؤال: أظهرنا كود إعداد فقط — فكيف يستخدمه شخص عادي فعلاً؟ الجواب: يحتاج تطبيقاً واحداً يدعم MCP (مساعد ذكاء اصطناعي)، ويضيف فيه رابط Talaix. لا يُنزّل أي شيء من Talaix، ولا يُثبّت خدمة.

الخلاصة

نعم، يلزمه برنامج واحد: تطبيق ذكاء اصطناعي يدعم MCP. أمّا Talaix فهي خدمة سحابية عبر رابط واحد — لا تنزيل ولا تثبيت.

01

الفكرة ببساطة

ما هو MCP؟ ولماذا يُظهر كوداً في مكان ما؟

ما هو MCP؟

MCP (بروتوكول سياق النموذج) معيار يسمح لتطبيق الذكاء الاصطناعي باستدعاء أدوات خارجية جاهزة — بدل أن يخمّن. بدل أن «يتكلّم» فقط، صار يستطيع أن ينفّذ.

Talaix تعرّف أدواتها التسع عبر هذا المعيار، فيستدعيها المساعد مباشرة.

ماذا يوفّر Talaix؟

رابط واحد فقط:

https://talaix.com/api/mcp
  • لا تسجيل مطلوب للتحليل للقراءة.
  • 9 أدوات: تحليل مخاطر، تحقّق من أصل، ملف تأميني، مطابقة خرائط، أوراق، مصادر…
  • الحدّ: 30 طلباً/دقيقة لكل عميل.
02

ماذا يحتاج المستخدم بالضبط؟

ثلاثة أشياء، واحد منها فقط يُنزَّل.

١ · يُنزَّل

تطبيق ذكاء اصطناعي يدعم MCP — مثل Claude Desktop أو Cursor أو VS Code مع Copilot. هذا هو «العميل».

٢ · يُنسَخ

رابط Talaix — يُضاف في إعدادات MCP داخل التطبيق (سطر واحد).

٣ · اختياري

حساب Talaix — مطلوب لاحقاً فقط لضوابط الحوكمة (صلاحيات لكل وكيل، موافقات، تدقيق). التحليل للقراءة لا يحتاجه.

03

أربع خطوات

من الصفر إلى أول استدعاء، في دقائق.

1

نزّل تطبيقاً يدعم MCP

Claude Desktop أو Cursor أو VS Code (+ Copilot)… افتحه وسجّل الدخول بحسابك فيه.

2

افتح إعدادات MCP

غالباً: الإعدادات → MCP، أو ملف إعداد mcp.json، أو «Connectors» في Claude.

3

الصق الإعداد

أضف خادم Talaix في قائمة الخوادم، ثم أعد تشغيل التطبيق.

4

اطلب من المساعد

اكتب طلباً عادياً، مثل: «حلّل خطر الفيضان والحرائق في 45.42، 12.33». فيستدعي المساعد أدوات Talaix ويعطيك النتيجة.

04

كيف تضيفه في كل تطبيق

التفاصيل الدقيقة تختلف بحسب إصدار التطبيق — راجع توثيق تطبيقك عند اللزوم.

التطبيقكيفالإعداد
Claude Desktop / Claude.ai الإعدادات → Connectors → «Add custom connector» والصق الرابط. أو ملف claude_desktop_config.json. 
{ "mcpServers": { "talaix": { "url": "https://talaix.com/api/mcp" } } }
Cursor ملف ~/.cursor/mcp.json (عام) أو .cursor/mcp.json (للمشروع)، أو الإعدادات → MCP. 
{ "mcpServers": { "talaix": { "url": "https://talaix.com/api/mcp" } } }
VS Code (Copilot) ملف .vscode/mcp.json — لاحظ أن المفتاح هنا servers لا mcpServers. 
{ "servers": { "talaix": { "type": "http", "url": "https://talaix.com/api/mcp" } } }
Claude Code (سطر أوامر) أمر واحد في الطرفية. 
claude mcp add --transport http talaix https://talaix.com/api/mcp
Windsurf · Cline · Continue · Zed · LM Studio تطبيقات تدعم MCP؛ أضف الخادم من ملف/شاشة MCP الخاصة بها بالصيغة نفسها (mcpServers → url). url: https://talaix.com/api/mcp
05

هل يلزم تنزيل برنامج أو خدمة؟

نعم تطبيق العميل

يجب أن يكون لدى المستخدم تطبيق ذكاء اصطناعي يدعم MCP. بعضها مجاني (Cursor، VS Code، Claude Code) وبعضها باشتراك (Claude Pro/Max).

لا من جهة Talaix

Talaix خدمة سحابية عبر رابط. لا يُنزّل المستخدم أي برنامج من Talaix، ولا يُشغّل أي خادم، ولا يحتاج VPN أو فتح منافذ.

استثناء واحد: بعض التطبيقات القديمة تدعم فقط الخوادم المحلية (stdio). عندها تحتاج جسراً صغيراً باسم mcp-remote (يعمل بـ npx ويتطلّب تثبيت Node.js). التطبيقات الحديثة التي تدعم النقل عبر HTTP (Streamable HTTP) لا تحتاج أي جسر.
06

ملاحظات تقنية مهمّة

النقل

  • النقل: Streamable HTTP (طلب/استجابة) — بلا بثّ SSE في هذه النسخة.
  • عامّ للقراءة فقط، بمعدّل 30 طلباً/دقيقة.
  • تم التحقق: الخادم يستجيب الآن بـ protocolVersion 2025-06-18 و9 أدوات.

ماذا يستطيع أن يسأل؟

  • «ما مستوى خطر الحرائق في موقعي؟»
  • «تحقّق من هذا الأصل لمتطلبات DNSH».
  • «ما تاريخ الأحداث لهذا الموقع؟»
  • «ما مصادر البيانات المتاحة، وما غير المتاح؟»

الأمانة مدمجة: الأدوات تعلن حدودها (لا ادّعاء اعتماد، لا تقدير خسائر، البيانات غير المتاحة تُعلَن ولا تُختلق). وضوابط الحوكمة (صلاحيات لكل وكيل، موافقات بشرية، سجل تدقيق) هي الطبقة الإضافية التي تُدار من حساب Talaix.
